# Python and Statistics for Financial Analysis
## A collection of notebooks and mini-projects completed during a Coursera course.

The contents of each notebook are as follows.

- simple_trading_strategy.ipynb : We explore an elementary hedging approach, where we long a stock if its short-time moving average exceeds its long-time moving average.
- model_of_stock_return.ipynb : Log-returns, estimating risky events, Value at Risk (VaR)
- sampling_and_inference.ipynb : Sampling with/without replacement, unbiased estimators, central limit theorem, confidence intervals, hypothesis testing
- linear_regression_models_in_finance.ipynb : Covariance, correlation, scatter plots, autocorrelation, linear regression, independence, normality, Durbin-Watson statistic, QQ plots
- multiple_linear_regression_trading_strategy.ipynb : Data munging/splitting/exploration/fitting, prediction, model evaluation (RMSE, adjusted R^2), trading strategy, Sharpe ratio, maximum drawdown
